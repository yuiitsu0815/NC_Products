# NC_Tools

Nemoharu Creative の配布用ツールのダウンロード置き場です。ファイルは [Releases](https://github.com/yuiitsu0815/NC_Tools/releases) にあります。
Downloads for Nemoharu Creative tools. Files are on the [Releases](https://github.com/yuiitsu0815/NC_Tools/releases) page.

ソースコードはここには置いていません。
Source code is not hosted here.

## ツール / Tools

| ツール / Tool | 内容 / Description | 対応 / Requirements |
| --- | --- | --- |
| NC_SmartScreenShot | シーケンスマーカーの位置のフレームを PNG（8/16bit）・JPEG で一括書き出しする Premiere Pro プラグイン<br>A Premiere Pro plugin that exports the frames at your sequence markers as PNG (8/16-bit) or JPEG in one go | Premiere Pro 2025 (25.6+) – 2027 / Windows・macOS |

## インストール / Install

1. Release から使う言語の `.ccx`（`_ja` = 日本語 / `_en` = English）をダウンロード
   Download the `.ccx` for your language (`_ja` = Japanese / `_en` = English) from Releases
2. ダブルクリックしてインストール（Creative Cloud にサインインしておく）
   Double-click it to install (sign in to Creative Cloud first)
